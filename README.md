# oedipamaas

Moteur iconographique : traduit une description d'image écrite en mots (sujet, personnes, objets, relations, concepts,
textes…) en codes Iconclass, chaque code avec sa preuve. Il tourne hors ligne, sans appel payant, et se rejoue sur
toutes les descriptions déjà faites.

État : conception. Voir [CONCEPTION.md](CONCEPTION.md).
