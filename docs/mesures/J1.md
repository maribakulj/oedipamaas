# Première mesure du moteur V1 (fin de J1, 23 novembre 2026)

Le moteur V1 (UDPipe → assertions → T1, T2, T6) sur des **titres** de la partie dev du corpus (jamais la partie
test) : 1 000 titres anglais, 500 titres français. Commande Prolog seule (`socle/commande.pl`), puis
`outils/mesure/etablis.py`.

## Résultats

| | Anglais | Français |
|---|---|---|
| titres | 1 000 | 500 |
| erreurs (document non traité) | 2 | 4 |
| titres avec au moins un code établi | 572 (57 %) | 198 (40 %) |
| codes établis | 1 028 | 260 |

| précision **hiérarchique** contre le catalogue (le code est un code du catalogue ou l'un de ses ancêtres) | 0,174 [0,152 ; 0,197] | 0,312 [0,262 ; 0,365] |

## Ce que ces chiffres disent, et ne disent pas

**Ce n'est pas la précision du § 12.2** (≥ 95 %, jugée sur ce que le texte soutient). C'est une borne basse : un
code juste que le catalogueur n'a pas mis compte comme faux. L'écart vient de trois sources, à séparer au J2 par le
jugement à la main d'un échantillon :

1. **Le catalogue code l'épisode, le moteur la personne ou la chose.** « Hagar and the angel » : catalogue `71C11932`
   (épisode d'Agar), moteur `11I63(HAGAR)` (Agar, personnage) — les deux sont dans des branches différentes, aucun
   n'est l'ancêtre de l'autre. Probablement juste du point de vue du texte, non confirmé par le catalogue.
2. **Le catalogue ne code pas tout ce que dit le titre** (un objet, un lieu, un animal secondaire).
3. **De vraies erreurs de règle**, visibles dans les exemples :
   - T1 prend des notations à nom qui ne sont pas des personnes : « John » → `46A1241(ST. JOHN)` (ordre de Saint-Jean),
     « Paris » (la ville) → `95A(PARIS)` (Pâris, le héros), « Égypte » → `98B(PSAMMETICHUS)` (par un mot clé) ;
   - T2 prend un mot du titre hors de son sens (« Kings », « Chronicles » des livres bibliques → `44B113`, `49K12`) ;
   - T6 remonte parfois vers une branche étrangère au sujet (« supper » → `41C4` repas, quand le catalogue code la Cène).

## Ce qu'il faudrait faire ensuite (à décider)

- Restreindre T1 aux **gabarits de personnes** (saints, personnages bibliques, mythologiques, historiques) et exiger
  qu'un nom de lieu reconnu comme tel (« Paris », « Égypte ») ne passe jamais par T1.
- Faire peser le **sujet de la phrase** : un nom propre complément d'un titre de livre (« Book of Kings ») n'est pas
  un référent représenté.
- Mesurer la **précision jugée sur le texte** (J2) sur un échantillon de 150 à 200 codes par type, avec la grille du
  § 12.4, avant de corriger davantage : sans ce jugement, on optimiserait vers le style du catalogue.
