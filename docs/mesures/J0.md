# Mesure de référence J0 (23 novembre 2026)

Ligne de base avant la V1 : le socle 1.0 tel qu'il est, après les corrections du J0, sur des **titres anglais**.

## Protocole

- Corpus : moisson du 23 novembre 2026 (`outils/moisson/moisson.py`, manifeste `manifeste-corpus.json`) ; partie
  **dev** seulement (la partie test n'est pas lue) ; 1 000 œuvres tirées par empreinte de l'identifiant parmi les
  65 206 œuvres dev qui ont un titre anglais et au moins un code hors division 86.
- Entrée : le titre seul, comme sujet d'une description (`{"subject": {"title": …}}`).
- Référence : les codes du catalogue (RKD, Wikidata P1257), division 86 écartée.
- Moteur : socle au commit de J0.11 ; base Iconclass `0595358`, WordNet 3.0.
- Mesures (`outils/mesure/mesure.py evaluer`) : F1 exact et H-F1 (préfixes par jetons) des k premiers du classement
  BM25 du socle (`socle/coder.py`) ; rappel des candidats du socle (`socle/candidats.py`, budget 60). Intervalles à
  95 % par rééchantillonnage (1 000 tirages, graine 0).

Commandes :

```bash
python3 outils/mesure/mesure.py preparer /home/user/donnees/corpus/corpus.jsonl /home/user/donnees/mesure-J0 --n 1000 --langue en
python3 -m oedipamaas.socle.coder /home/user/donnees/base /home/user/donnees/mesure-J0/descriptions /home/user/donnees/mesure-J0/coder.jsonl

```

## Lecture

- Ce sont des **lignes de base contre le catalogue**, pas une mesure de la précision des codes établis (§ 12.2 du
  cahier des charges) : un titre ne dit pas tout ce que le catalogueur a codé (paysage, figures, objets vus sur
  l'image), et un code juste absent du catalogue compte comme faux.
- Un titre seul ne permet au socle de proposer exactement que 30 % des codes du catalogue, et d'en couvrir 56 % par
  la hiérarchie : c'est le plafond de rappel d'un moteur qui ne lit que le titre.
- Biais connu (annexe A) : une partie des titres Wikidata reprend presque mot pour mot les libellés d'Iconclass.
- La version 0.2 n'est pas mesurée ici : ses poids appris ne sont pas dans le dépôt.
